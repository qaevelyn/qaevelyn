## The stance

Fail-closed. Local-first. No versions — the filename is the name. Path agnostic — search for the anchor, not the path. One anchor in the storm. The tools are standing remedies: when a failure class recurs, apply the existing ship, don't invent a patch. Every claim traceable to evidence; where evidence is missing, abstain.
